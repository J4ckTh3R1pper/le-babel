# 项目简介(WIP)
本项目是一个支持Markdown格式、树状评论展示和翻译功能的网络论坛系统，由基于Spring Boot、Spring Data、Hibernate、Spring Security、MariaDB、Redis的后端程序和基于Vue 3.5、Vue Router、Pinia、Element-UI的前端程序组成，后端基于Spring Security和JWT进行用户认证
# 项目结构
前端：vite  
后端：src/java
# 开发环境搭建
前端：在前端根目录下执行Node包管理器执行dev命令（以yarn为例）  
```shell
yarn dev
```
# 项目部署
前端：在前端目录下使用Node包管理器执行构建命令后访问dist目录中的index.html(以yarn为例)  
```shell
yarn run vite build
```  
后端：运行gradle任务jar后在build/libs中找到jar包
